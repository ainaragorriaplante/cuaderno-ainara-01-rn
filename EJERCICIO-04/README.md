# Ejercicio 04 - Pantalla de acceso

## Qué he aprendido
- A utilizar el componente 'TextInput' para recoger entradas de texto, empleando 'placeholder' para mostrar textos de ayuda y 'secureTextEntry' para ocultar caracteres sensibles en contraseñas.
- A diseñar botones visuales interactivos utilizando el componente 'Pressable'.

## Respuesta a la pregunta de comprensión
¿Por qué en este ejercicio no necesitamos todavía `useState`?

Respuesta:
Porque todavía estamos trabajando en el diseño únicamente y no gestionar la entrada de datos

## Qué he modificado
- He cambiado el colores para que quede como en la imagen, y he configurado adecuadamente los campos de entrada y los textos de ayuda ('placeholderTextColor') para mantener la claridad de los campos

## Resultado
Explica brevemente cómo ha quedado la interfaz.
La interfaz muestra una tarjeta centrada con un título de bienvenida, un subtítulo,
